# Exercise: Coding with AI Assistance

In this group exercise, you will use a chatbot to support a small research-data project from planning through analysis. The goal is not to let the chatbot do the research for you. You will decide what to ask, write or adapt the code, run it yourself, and check the results.

## Before you begin

1. Form a group of 3-4 people and choose a dataset track:
   - `social_sciences`
   - `life_sciences`
   - `engineering`
2. Open the `README.md` in your track folder. It describes the research question, the data, and its source.
3. Use a chatbot account available to your group. You may use any chat-based coding assistant.

Do not upload sensitive, confidential, or identifiable data to a chatbot. The exercise datasets are provided for this workshop; in your own research, follow your project’s data-use requirements.

## What to do

Work through the following stages with your group. You do not need a perfect or complete analysis. Make deliberate choices, test your code, and be ready to explain your reasoning.

### 1. Plan the project

Before opening the data, translate the research question into a small, concrete computational task.

- Write a short plan: the question, proposed methodological approach, key steps, and expected output.
- Ask the chatbot to help you brainstorm a plan, but check that its suggestions fit the question and dataset.
- Decide what data files, scripts, and outputs your project will need.

### 2. Explore and clean the data

Use code to load and inspect the raw data.

- Identify the observations, variables, file format, missing values, and any data-quality issues that matter for your question.
- Ask for code in small pieces: for example, code to inspect column names, summarize missingness, or check a suspected issue.
- Write and run cleaning code. Save the resulting dataset only when you can explain what changed and why.
- Verify the cleaning worked by checking row counts, values, summaries, or other relevant outputs.

If you do not finish this stage, you may use the provided clean data to continue.

### 3. Work with existing code

Your track includes a `post_doc_code` file: code left by a fictional postdoc or collaborator.

- Read the code before running it.
- Use the chatbot to explain unfamiliar sections, identify assumptions about the data, and suggest focused changes.
- Decide whether the code is appropriate for your data and research question. Adapt, replace, or set aside code as needed.

### 4. Analyze and visualize

Use the clean data to address the research question.

- Ask for code to carry out one manageable analysis and create one useful visualization.
- Review and run the code yourself.
- Check whether the result is plausible given the data and the research context.
- Draft a 2-3 sentence description of what you found, including appropriate uncertainty or limitations.

### 5. Prepare a brief readout

Be ready to give an informal 3-minute report to the room. Include:

- the research question;
- the methodological approach you chose;
- one result or visualization;
- one moment when your group applied, revised, or challenged an AI suggestion.
